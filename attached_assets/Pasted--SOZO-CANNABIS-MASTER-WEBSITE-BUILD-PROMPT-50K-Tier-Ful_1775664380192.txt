## AESTHETIC DIRECTION — NON-NEGOTIABLE

### Codename: "BOTANICAL LUXE"

Think: **luxury editorial magazine meets high-end botanical brand meets Chicago architect's apartment.**

- **Mood:** Darkly elegant. Organic warmth against deep forest tones. Gold accents that feel earned, not flashy.
- **NOT:** Generic green dispensary. Not neon. Not streetwear. Not pharmaceutical.
- **References:** Aesop's website aesthetic + Off-White's editorial grid + Kinfolk magazine's photography treatment.

### Typography System
- **Display / Hero:** `Cormorant Garamond` — elegant, high-contrast serif with Italian editorial energy. Used for all hero headlines, section titles, pull quotes.
- **Subheadings:** `Freight Display Pro` or `DM Serif Display` — warm, readable serif for mid-level headers.
- **Body / UI:** `Söhne` (or `Neue Haas Grotesk` fallback `DM Sans`) — Swiss grotesque with personality. Clean, modern, slightly warm.
- **Accent / Labels:** `Neue Montreal` or `Aktiv Grotesk` — tight, uppercase, letter-spaced for eyebrows, badges, nav items.
- **Size scale:** Display: 96px / Hero: 72px / H1: 56px / H2: 40px / H3: 28px / H4: 20px / Body: 16px / Caption: 13px / Label: 11px

### Motion & Animation System
- **Page load:** Staggered fade-up reveals with `opacity: 0 → 1` + `translateY(24px → 0)` at 60ms intervals per element
- **Scroll animations:** `IntersectionObserver` triggers class `.in-view` — all major sections animate in from slight transforms
- **Hover states:** Cards lift `translateY(-6px)` with box-shadow deepening over 300ms cubic-bezier(0.34, 1.56, 0.64, 1)
- **Image hover:** Subtle 1.04 scale on product images, 500ms ease
- **Nav:** Transparent on hero, transitions to dark solid on scroll with backdrop-blur: 20px
- **Custom cursor:** Circular 32px cursor that scales to 48px on hover over interactive elements, shifts to crosshair on product images
- **Page transitions:** 400ms fade with slight upward motion between pages
- **Micro-interactions:** Button press ripple effect. Input focus ring animated width expand. Badge pulse on "Open Now."
